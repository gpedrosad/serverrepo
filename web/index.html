Retro76 — Open Tibia Server chileno 7.6

Retro76 es un OT server chileno de Tibia 7.6 (Open Tibia), alojado con baja latencia para Chile y Latinoamérica. Revive el Tibia clásico: PvP retro sin protecciones modernas, runas, vocaciones promovidas y economía de jugadores.

Además del contenido clásico, Retro76 tiene sistemas propios que no vas a encontrar en otro servidor: minería de gemas e imbuiciones, El Crisol con rares diarios, Wave Arena, arena de fosos, tareas diarias del Huntmaster e items custom. La cuenta es gratis y el cliente viene listo para Windows y macOS.
