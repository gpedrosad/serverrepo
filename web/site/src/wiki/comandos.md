## Lo esencial

- Se escriben en el canal **Default**, tal cual, empezando con `!`.
- Nadie más los ve. La respuesta te llega solo a ti.
- Los más usados son `!pz`, `!frags` y `!premmy`.
- En otros canales (Game Chat, privados) no funcionan.

## Lista de comandos

| Comando | Qué hace |
|---|---|
| `!pz` | Dice si tienes PZ lock y cuánto falta para que se quite. |
| `!frags` | Cuántos frags tienes y cuánto falta para perder el siguiente. |
| `!premmy` | Cuánto tiempo de premium te queda. |
| `!exp` | Cuánta exp te falta para subir de nivel. |
| `!mana` | Cuánta mana te falta gastar para subir de magic level. |
| `!online` | Lista de jugadores conectados, con su nivel. |
| `!house` | Recarga tus permisos de casa. |
| `!uptime` | Cuánto tiempo lleva encendido el servidor. |
| `!report texto` | Deja un mensaje escrito para el staff. |

## Cuándo usar cada uno

- **`!pz`** antes de correr al templo después de una pelea. Si tienes PZ lock, no puedes entrar a zonas protegidas. Ver [[pvp]].
- **`!frags`** para saber si estás cerca del red skull. Los frags bajan solo mientras estás conectado.
- **`!house`** si te acaban de invitar a una casa y la puerta todavía no te deja pasar.
- **`!report`** con el detalle después del comando, por ejemplo `!report vi un bot en los dragones del norte`.

> **Tip:** para administrar tu casa (invitados, dueños de puertas, echar a alguien) se usan palabras como `aleta sio` y `alana sio`, que no empiezan con `!`.
